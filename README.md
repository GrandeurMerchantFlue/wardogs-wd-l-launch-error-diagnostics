## 📁 How It Works — Troubleshooting Workflow

1. Capture the full WD-L error code; different codes may require different troubleshooting.
2. Verify WARDOGS game files through Steam.
3. Open the WARDOGS install directory, locate Elytra, run its official setup and choose Repair if available.
4. Update the graphics driver, reboot and test the game without GPU or CPU overclocking.
5. If instructed by the developer, test a different connection, such as a mobile hotspot, to isolate a network issue.
6. Share the exact error code, logs and steps already tried in the developer’s pinned support discussion.
